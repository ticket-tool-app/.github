# Ticket Tool

A complete support system for Discord servers. Members open tickets from a panel or a slash command, staff work them in Discord or from the web dashboard, and every ticket is logged and transcribed.

[ticket-tool.app](https://ticket-tool.app) · [Documentation](https://ticket-tool.app/docs) · [Dashboard](https://dash.ticket-tool.app) · [Support server](https://ticket-tool.app/discord)

## What we build

- Ticket categories and panels, each with their own permissions, forms and messages
- A visual flow builder for intake, routing and follow-up
- Automation rules, integrations, webhooks and a public REST API
- A knowledge base with semantic search and a hosted public portal
- Analytics, SLA tracking and CSAT surveys
- AI Assist for suggested replies, classification and routing

## Repositories
